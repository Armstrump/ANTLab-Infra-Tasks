## 选题

方向一：KV 缓存管理与复用优化

## 应用场景

7 人工作室反复查询同一份项目文档、分析同一段代码、或继续已有会话。每次请求都重新计算输入 token，浪费算力。目标是通过缓存文档的输入 token，让后续相同文档的请求减少重复计算，降低 TTFT。

## 优化目标

- 同一文档、不同问题时，复用文档的输入 token
- 对比复用前后 TTFT 的变化
- 记录缓存命中率和复用 token 比例

## 实现内容

- 写一个文件快照代理，缓存文档的输入 token
- 第二次请求同一文档时，复用缓存
- 记录并对比复用前后的 TTFT

## 目录结构

- `src/`：代理脚本和测试脚本
- `results/`：原始数据和对比结果
- `reports/`：书面报告
